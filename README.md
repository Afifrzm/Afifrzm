## 🚀 SoftApproval

One of the projects I'm currently building is **SoftApproval**.

The idea grew out of a simple security problem:

> Evaluating software before allowing it into an organization can involve a surprising amount of manual research and workload.

Security teams may need to investigate vendors, vulnerabilities, software reputation, security characteristics, and other evidence before making a decision.

SoftApproval explores how parts of that workflow can be structured and automated.

The implementation, internal logic, assessment methodology, and source code are private for now, but the project has become one of the main ways I'm exploring the intersection of:

**Cybersecurity × Software Engineering × Automation**
